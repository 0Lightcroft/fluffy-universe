# Lightcroft — Fluffy Projects

Site vitrine statique officiel du dépôt `0Lightcroft/fluffy-universe`.

## Contenu

- `index.html` : page d'accueil et présentation des projets.
- `assets/site.css` : style responsive, sans framework ni JavaScript.
- `404.html` : page d'erreur personnalisée.
- `.nojekyll` : désactivation de la transformation Jekyll sur GitHub Pages.
- `robots.txt` : autorisation d'indexation.

## Projets présentés

- **FluffyFighter** — jeu vidéo principal.
- **FluffyCard** — création de cartes, decks, plateaux et règles, essais 2D/3D.
- **FluffyDraw** — logiciel de dessin et de création graphique.
- **Fluffy Engine** — moteur commun aux projets.
- **À venir** — extension de l'écosystème.

## Direction artistique — fidèle à FluffyCard

Références : `cardcraft.css`, `tycreator-tokens.css`, `cardcraft-fonts.css`, `fluffy-loading.css` fournis par le développeur.

| Token | Valeur |
| --- | --- |

| Feuille claire | `#faf8f3` |
| Papier profond | `#ebe5da` |

Le relief carton est réalisé uniquement avec CSS : papiers superposés, tranche striée, gravure, filet bronze, grain SVG. Les éléments décoratifs ne sont **pas** des captures réelles des applications. La photo de profil est chargée depuis l'avatar GitHub de `0Lightcroft`.

Les polices sont chargées depuis Google Fonts, sans redistribuer les fichiers de police locaux du projet.

## Mise en ligne gratuite — GitHub Pages

1. Ouvrir **Settings → Pages** de ce dépôt.
2. Sous **Build and deployment**, choisir **Deploy from a branch**.
3. Sélectionner **main** puis **/(root)** et enregistrer.
4. Le site doit ensuite devenir accessible à l'adresse :
   `https://0lightcroft.github.io/fluffy-universe/`

Le lien public ne sera opérationnel qu'une fois GitHub Pages activé et le déploiement terminé.

## Actualisation

- Les textes et les sections se modifient dans `index.html`.
- Les couleurs, la texture et le carton se modifient dans `assets/site.css`.
- Les liens de téléchargement ou réseaux sociaux doivent être ajoutés uniquement une fois vérifiés.

## Confidentialité / Google Play

La politique de confidentialité de **FluffyCard** n'est pas rédigée ici : les pratiques effectives de collecte et de partage de données ne sont pas documentées dans les fichiers CSS. Ne pas déclarer « aucune collecte » sans vérification du code et des services tiers. Une politique spécifique, complète et conforme aux exigences de Google Play devra être publiée séparément, puis rendue accessible dans FluffyCard. Ce site seul **ne constitue pas** une politique de confidentialité.

## Dépendances

Aucune dépendance JavaScript, aucun build, aucun suivi analytique intégré. Une connexion Internet est nécessaire pour charger la police Google Fonts et l'avatar GitHub (les polices de repli fonctionnent hors ligne).
