# Lightcroft

Site de présentation de Fluffy Fighters et des logiciels liés au jeu : FluffyCard, FluffyDraw et Fluffy Engine. Customization y figure comme projet complémentaire, avec une page dédiée à son test Android.

Adresse : https://0lightcroft.github.io/fluffy-universe/

Le site fonctionne directement sur GitHub Pages, sans installation ni compilation.

- `index.html` : projets et contact.
- `tester-fluffyfighter-customization.html` : présentation du créateur et liens Google Groups / Google Play.
- `assets/site.css` et `assets/site.js` : présentation, animations discrètes et choix français/anglais.
- `privacy-fluffyfighter-customization.html` et `support-fluffyfighter-customization.html` : confidentialité et assistance.
- `checklist-test-android.html` : fiche de test imprimable.
- `recrutement.html` : outil de préparation des annonces, hors navigation publique et non indexé.

Les captures du créateur proviennent de l’application. Les anciennes illustrations ne sont plus affichées. Les traductions française et anglaise sont incluses dans les pages ; aucun service de traduction automatique n’est chargé. Le choix de langue est mémorisé dans le navigateur. Aucun outil de suivi d’audience n’est ajouté.

Les animations respectent la préférence « réduire les mouvements ». Tous les textes et liens essentiels restent accessibles sans JavaScript.
